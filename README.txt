# TERRYGES V1.1.0 — Web

Página web estática lista para GitHub Pages.

## Estructura
- index.html
- assets/branding/terryges_logo.png
- assets/capturas/01-login.jpg ... 10-carga.jpg

No requiere Node, Flutter ni servidor: GitHub Pages puede servirla directamente.

## Publicación
Sube todo el contenido de esta carpeta al repositorio y habilita GitHub Pages desde:
Settings → Pages → Deploy from a branch → main → / (root).
